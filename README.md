# Florida Keys fishing tides

Standalone tide + weather page for Oct 19–25, 2026 (Sugarloaf, Marathon, Key West).

Open `keys-tides-oct19-25-2026.html` in a browser, or use GitHub Pages.

## GitHub Pages

1. On GitHub, click **New repository**.
2. Name it `keys-tides` (or anything). Public.
3. Do **not** add a README if you will upload this folder as-is.
4. Click **uploading an existing file**.
5. Drop in `keys-tides-oct19-25-2026.html` and this `README.md`.
6. Commit.
7. Repo → **Settings** → **Pages**.
8. Source: **Deploy from a branch**. Branch **main**, folder **/ (root)**. Save.
9. After a minute the site is:

   `https://YOUR_USERNAME.github.io/keys-tides/keys-tides-oct19-25-2026.html`

To get a cleaner URL, rename the html file to `index.html` before upload. Then the site is:

   `https://YOUR_USERNAME.github.io/keys-tides/`
